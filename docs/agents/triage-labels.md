# Triage 標籤

技能以五個標準的 triage 角色溝通，本表把這些角色對應到本 repo tracker 裡實際使用的標籤字串。

| mattpocock/skills 的標籤 | 本 repo 的標籤 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等維護者評估 |
| `needs-info` | `needs-info` | 等回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交給無人值守的 agent |
| `ready-for-human` | `ready-for-human` | 需要由人實作 |
| `wontfix` | `wontfix` | 不會處理 |

技能提到某個角色時（例如「套用 AFK-ready 的 triage 標籤」），使用本表對應的標籤字串。要改用其他名稱，直接修改右欄。
