# 合成範例資料：Northwind Precision（虛構製造業公司）

> **所有資料皆為合成（synthetic）**。公司、主機名稱、IP、帳號、弱點編號（`SYN-` 開頭）與威脅情資皆為示範用途而虛構，與任何真實組織、產品或 CVE 無關。請勿以本資料推論任何真實環境的安全狀態。

本目錄提供一份完整、可直接餵給五個平台 skill 的輸入資料集，同時也是網站「案例互動展示」使用的資料。

| 檔案 | 對應輸入類別 | 必要性 | 說明 |
|---|---|---|---|
| `assets.csv` | 資產清冊 + 業務重要性 | 必要 | 12 筆資產，含類型、擁有者、業務重要性（1–5）、資料等級、是否對外曝露 |
| `exposures.json` | 外部曝險（EASM 輸出） | 必要（可由資產清冊推估） | 對外服務、port、憑證與到期、指紋 |
| `vulnerabilities.csv` | 弱點掃描結果 | 必要 | 合成弱點（`SYN-2026-xxxx`），含 CVSS、是否有公開利用程式、模擬 EPSS、模擬 KEV 旗標 |
| `misconfigurations.csv` | 設定基準偏差 | 選用 | CIS/雲端設定檢查結果 |
| `identities.csv` | 身分與權限 | 選用（建議） | 特權帳號、MFA 狀態、閒置狀態、服務帳號 |
| `controls.json` | 既有控制措施 | 選用（建議） | EDR、WAF、網段隔離、備份、日誌覆蓋 |
| `threat-intel.json` | 威脅情資 | 選用（建議） | 產業相關威脅行為者 TTP、近期活躍利用之弱點類別 |
| `topology.json` | 網路／信任關係 | 選用 | 資產間可達性與信任邊，供攻擊路徑假設使用 |
| `scope.json` | 授權範圍與分析參數 | 必要 | 授權範圍、排除項、分析日期、風險胃納 |

執行方式請見各平台 skill 的「使用範例」，以及 `examples/expected-output.md` 內的預期輸出。
